# 🌿 AgroForte | Dashboard Agrícola

Painel conceitual e futurista para monitoramento de agricultura regenerativa, integrando dados de IoT, automação e créditos de carbono.

## 🛠️ Tecnologias
* **HTML5 / CSS3** (Fontes *Orbitron* e *Rajdhani*)
* **Tailwind CSS** (Estilização e layout responsivo)
* **Chart.js** (Gráfico interativo de rendimento)
* **Lucide Icons** (Ícones da interface)

## 💻 Como Rodar o Projeto
Por utilizar dependências via CDN, o projeto não precisa de instalação:
1. Salve o código em um arquivo chamado `index.html`.
2. Abra o arquivo diretamente em qualquer navegador web.

## 📋 Funcionalidades Principais
* **Métricas em Tempo Real:** Monitoramento de umidade do solo, saúde da plantação e reserva hídrica.
* **Gráfico Histórico:** Comparativo entre produtividade e carbono absorvido.
* **Status de Automação:** Painel com nível de bateria de drones e irrigadores.
* **Seção de IA:** Recomendações e avisos meteorológicos preditivos.
